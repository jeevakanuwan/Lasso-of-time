# The Lasso of Time

Science-fiction novel project about love, extinction, time warfare, and the danger of trying to erase an enemy before it can exist.

## Structure
- `01_story_bible/` — canon, characters, technology, themes.
- `02_timeline/` — chronological and causal timelines.
- `03_sections/` — four acts and 24 chapters.
- `04_science/` — scientific grounding and speculative extensions.
- `05_conversation/` — author/AI decisions and plot evolution.
- `06_drafts/` — full prose drafts.
- `07_revisions/` — continuity and revision notes.

## Core technology
**AION — Acausal Isolation and Observer Nullification**, nicknamed the **Stillhouse**. It is inspired by a Faraday cage but isolates a local causal reference frame rather than blocking electromagnetic fields.
